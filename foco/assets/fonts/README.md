# Foco web fonts

Manrope (variable 400–800) and IBM Plex Mono (500), served locally as WOFF2.
Latin includes the accented characters used by the Spanish site; Latin Extended
is fetched only when needed. Both fonts use SIL Open Font License 1.1; the
original license and copyright notices are included in this directory.

Source: Google Fonts CSS API, retrieved 2026-09-22, font revision v20.
https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@500&family=Manrope:wght@400..800&display=swap

Font files are versioned. Use a new filename when updating them so browser caches
never mix revisions. Current-page builds replace the external font stylesheet;
accepted policy archives are intentionally preserved byte-for-byte.
